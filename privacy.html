# Project Super Human — Privacy Policy **Last updated:** November 9, 2026 ## 1. Purpose Project Super Human is a personal health analytics application designed to consolidate and analyze physiological, sleep, recovery, and fitness information obtained from authorized wearable devices, including WHOOP. ## 2. Information Collected With the account holder's authorization, the application may access profile information, body measurements, heart rate variability, resting heart rate, recovery metrics, sleep records, workouts, and physiological data available through the WHOOP API. ## 3. Data Storage and Processing Health information retrieved through the WHOOP API is intended to be stored and processed locally on the account holder's personal computer. The application does not publish health records to this GitHub repository. ## 4. Use of Information Information is used for personal health visualization, longitudinal trend analysis, recovery monitoring, fitness analysis, and personal research. The application is not intended to provide medical diagnoses. ## 5. Data Sharing The application is not designed to sell personal health information or share it with advertisers. Information may pass through the network services required to authenticate and communicate with the WHOOP API. ## 6. Data Retention and Deletion Locally stored information remains under the account holder's control. The account holder may delete local data files and revoke application access through WHOOP's connected-app controls. ## 7. Security The application is designed to use OAuth authorization, restricted local credential storage, and encrypted HTTPS communication with WHOOP. ## 8. Changes This policy may be updated when the application's functionality or data-handling practices change. ## 9. Contact For privacy inquiries, contact the application operator through the Project Super Human GitHub repository.
